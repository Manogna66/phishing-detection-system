# 🔐 Phishing Detection System

A full-stack web application that analyzes URLs and detects potential phishing attacks using rule-based threat analysis and domain intelligence.

---

## 🚀 Features

- URL structure analysis
- Suspicious keyword detection
- Typosquatting detection
- Brand impersonation detection
- Domain age analysis (WHOIS)
- VirusTotal reputation check
- Risk score calculation
- Threat level classification
- Domain intelligence panel
- Scan history dashboard

## 🔎 How It Works

1. User enters a URL in the dashboard.
2. The frontend sends the URL to the backend API.
3. The backend analyzes the URL using multiple security checks:
   - URL structure rules
   - suspicious keyword detection
   - domain similarity detection
   - brand impersonation detection
   - domain age lookup
   - VirusTotal reputation check
4. The system calculates a **risk score** and determines if the URL is phishing.
5. Results are displayed in the dashboard.
